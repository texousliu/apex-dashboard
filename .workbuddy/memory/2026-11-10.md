## 修测试基础设施的「时间炸弹」（A 组的后续优先项）

上一轮 A 组修复时发现：`scripts/obsidian-stub.ts` 的 `moment()` 用的是裸 `new Date()`，直接读系统时钟，**不读被测试覆写的 `Date.now`**。于是 `verify-task-writes` 的两个日笔记用例在钉住的日期之外必红——只在写它的那一天通过。当日已改为 `new Date(Date.now())`，本轮把它做成了「不会再来一次」的结构。

### 四件事

1. **行为守卫** `scripts/verify-obsidian-stub.ts`（6 组，`npm run test:obsidian-stub`）：冻结后 `moment()` 必须报哨兵日期；解冻后必须回到真实时钟；date-only 字符串必须按本地零点解析（UTC 解析会让东时区日笔记路径差一天）；epoch 直通；抛异常的用例也必须还原时钟；未冻结时 `moment()` 与 `Date.now()` 同源（防止有人用硬编码常量「修」第 1 组）。
2. **冻结助手** `scripts/test-clock.ts`：`SENTINEL_NOW = '1999-12-31T10:00:00'` + `withFrozenNow()`（`finally` 还原）。哨兵必须是**不可能等于今天**的日期——原来钉的是 `2026-11-09`，如果时钟恰好是那天，冻结失效也照样绿。
3. **`verify-task-writes` 第 4/5 组改写**：手写 `Date.now = …` → `withFrozenNow`，fixture 路径改成 `Daily/1999-12-31.md`，并补 `assert.ok(rig.files.has(path))`——原来只是 `rig.files.get(path)!`，路径算错时报的是 `Cannot read properties of undefined`，看不出是时钟问题。
4. **`npm run audit:clock`**：`run-all-tests.mjs` 新增 `--clock-audit`，把 `scripts/fake-clock.cjs` 通过 `NODE_OPTIONS=--require` 预载进每个子进程（默认假时钟 2031-06-15），全量用例在假时钟下跑。

### 结果

- `--clock-audit` 全量 **117/117 通过**（269 s）→ 没有其它用例依赖墙上时间（所有硬编码日期都是输入 fixture，不是「今天」）。
- 反向对照做过：把 stub 改回裸 `new Date()`，`verify-obsidian-stub` 第 1 组红（actual `2026-11-10`）；`--clock-audit task-writes` 也红 → 证明假时钟确实穿透到子进程，不是空跑。
- `npm run check` 全绿：build + lint 0 error 0 warning + **117/117**（164 s）。

### 教训

- **冻结 `Date.now` 只对读 `Date.now()` 的代码有效**。`new Date()` / `performance.now()` 都绕过它。测试工具自己的时间源要单独测。
- **钉住的日期不能是「可能是今天」的日期**。哨兵的价值就在于「出问题时结果必然不同」。
- 「全量绿」必须配一个**反向对照**（把修复拿掉会红），否则分不清是检查有效还是检查没跑。
- 新写的文件要补行尾：仓库工作区是 CRLF，`Write` 出来的是 LF；`package.json` 被 JSON.stringify 重写后也变 LF，用一次性脚本转回 CRLF 后 `git diff` 才是纯新增（`4/1`、`20/0`）。

## 数据库分区加刷新按钮

`library` / `folder` 分区的工具栏补了刷新按钮（`dashboard-library-refresh-btn`，图标 `refresh-cw`），位置在每页条数之后、新建笔记之前。

- **为什么需要**：分区靠 vault 事件自动重绘，但 `refreshScanningSections` 先比渲染输入签名（path + mtime）。frontmatter 要等 metadata cache 解析完才出现时，文件没变、签名相同 → 永远不重建。排序/搜索/改每页条数都会顺带重新查询，所以此前只能靠点排序刷新。
- **为什么不走分区级刷新**：那会重建整条工具栏，搜索词清空、页码跳回第 1 页。按钮走 `renderContent(config)`，只换结果区，搜索词 / 页码 / 折叠分组全保留，页码超出范围时由 `renderContent` 自己 clamp。
- **`library.refresh` 键早就在 11 种语言里存在但代码从未引用**（大概是撤掉的旧按钮留下的），这次直接用上，没动语言文件。
- 新增 `scripts/verify-library-refresh.ts`（6 组，含「不点击不出现」的负向对照 + frontmatter 迟到场景）。三处变异验证：点击不查询 / 重置页码 / 清空搜索，均按预期红。`npm run check` 118/118（169 s）。
- 部署：备份到 `release/vault-backup-20261110-1115/`，新 `main.js` 5,118,564 B（sha `ea96f524…`），`styles.css` 896,982 B（sha `bdec8891…`，含新增 3 条规则）。`data.json` 未动。
