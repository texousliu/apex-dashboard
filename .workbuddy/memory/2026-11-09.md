## 关键教训/约定

- mini-dom 选择器引擎已支持逗号分组（我加的）；此前 src 里的逗号选择器在测试环境从不匹配。
- mini-dom 的 isConnected 要求根是 `new El('body')`——测试里挂在裸 div 下的元素会被 refresh bus 剪枝（verify-calendar-section 已改挂 body 根）。
- 部分源文件是 CRLF（pipeline-model/pm-model），部分 LF；脚本批量替换字符串时先确认行尾，多行匹配用单行替换更稳。
- tsc 通过 ≠ main.js 已重打包：提交前要跑 npm run build（切片 A/B 曾漏打包，C 里补上）。
- verify 脚本是 CJS bundle，不支持顶层 await，要包 async main()。
- Notice 桩的 messages 静态记录：`(Notice as unknown as { messages: string[] }).messages` 桥接真实类型。
